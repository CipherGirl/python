| Structure                            | Mutability | Typical Use                 |      Indexing / Lookup |          Insert (avg) |    Delete (avg) | Memory layout                                                | Good when...                                 |
| ------------------------------------ | ---------: | --------------------------- | ---------------------: | --------------------: | --------------: | ------------------------------------------------------------ | -------------------------------------------- |
| **list**                             |    mutable | ordered seq, stacks         |          O(1) by index | append O(1) amortized |      pop() O(1) | contiguous dynamic array of pointers (over-allocated)        | you need fast random access & dynamic growth |
| **dict**                             |    mutable | key→value mapping           | lookup by key O(1) avg |              O(1) avg |        O(1) avg | hash table (entries store key, value, hash)                  | fast mapping, indexing by arbitrary keys     |
| **tuple**                            |  immutable | fixed records, keys         |                   O(1) |     N/A (create O(n)) |             N/A | contiguous fixed-size array of pointers                      | you need immutability (safety / dict keys)   |
| **set**                              |    mutable | unique elements, membership |    membership O(1) avg |          add O(1) avg | remove O(1) avg | hash table of keys                                           | de-duplication, fast membership              |
| **stack** (`list` or `deque`)        |    mutable | LIFO                        |     O(1) to access top |             push O(1) |        pop O(1) | list uses dynamic array; deque uses block-linked ring        | undo stacks, recursion, backtracking         |
| **queue** (`deque` or `queue.Queue`) |    mutable | FIFO                        |    access to ends O(1) |          enqueue O(1) |    dequeue O(1) | deque: block-linked ring; queue.Queue wraps deque with locks | task scheduling, BFS, producer/consumer      |
